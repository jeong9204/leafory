# Phase 6 추천 영역 UI 간소화

카탈로그·검색·저장 흐름을 유지하며 추천 컴포넌트와 스타일만 수정했습니다.

- 기본 후보는 이름·학명 두 줄과 `자세히 보기` 버튼으로 구성합니다.
- 이름·학명 영역을 누르면 기존처럼 학명 필드만 채웁니다.
- 설명·Kew 출처·확인 날짜·이용 고지는 후보별 `자세히 보기`에서만 표시합니다.
  `닫기`를 누르면 다시 숨깁니다. 펼치기 동작은 학명 선택이나 폼 제출을 실행하지 않습니다.
- 상단은 제목·선택 표시·후보 수만 남겼습니다. 미등록 검색의 직접 입력/빈 값 안내는 유지합니다.
- 펼침 버튼은 독립된 `button`이며 후보별 접근 가능한 이름, `aria-expanded`,
  `aria-controls`를 제공합니다. 닫힌 영역의 링크는 키보드 탐색과 접근성 트리에서 제외됩니다.
  Enter/Space 조작, 포커스 표시, 최소 44px 터치 영역을 확인했습니다.
- 기존 로컬 Pretendard와 크림·세이지 컬러를 유지합니다. 320px와 390px에서 스투키
  2개 후보 영역은 약 204px 높이이며 가로 스크롤이 없습니다. 320px의 긴
  Philodendron bipinnatifidum도 카드 안에서 줄바꿈됩니다.

## 검증

추천 UI 테스트 4개를 추가했습니다. 기본 접힘·복수 후보, 키보드 펼치기/닫기,
출처 표시, 선택과 펼치기 분리, 검색 결과 교체 시 펼침 상태 초기화를 검증합니다.
기존 후보 선택·직접 학명 수정·미선택 저장·식물 등록/수정 테스트를 유지합니다.
전체 타입·린트·포맷·211개 테스트(19개 파일)·빌드를 `npm run check`로 확인했습니다.

실제 브라우저에서는 사용자 데이터와 분리된 5174 origin의 등록 폼에서 입력·선택·직접 수정·
키보드 펼치기/닫기를 확인했으며 저장이나 사용자 데이터 변경은 하지 않았습니다.
카탈로그 JSON, 검색 코드/테스트와 Dexie 스키마 파일은 변경 전후 SHA-256이 동일합니다.
모바일 확인은 viewport 기반이며 iOS/Android 실기기 검증은 포함하지 않습니다.
Git commit/push는 하지 않았습니다.
