# 홈 사진 자산

제작 방식: imagegen 스킬의 내장 이미지 생성 도구. 기존 첨부 시안의 분위기와 식물
종류를 참고했으며, 시안의 사진을 추출하거나 원본과 동일하다고 주장하지 않습니다.
생성 결과를 프로젝트에 복사하면서 JPEG로 변환하고 헤더는 최대 1200px,
썸네일은 최대 480px로 축소했습니다. 앱은 외부 이미지 서버에 의존하지 않습니다.
