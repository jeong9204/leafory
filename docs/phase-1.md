# Phase 1 — 홈 UI

첫 번째 첨부 시안인 식물 리스트형 홈을 기준으로 구현했습니다.

## 구현

- 창가 식물 사진과 그라데이션 배경, 한국 시간의 오늘 날짜, 정원 제목
- 식물 배열의 길이로 계산하는 식물 수와 월요일부터 오늘까지의 주간 기록 수
- `PlantCard` 컴포넌트: 사진·이름·학명·상태·물주기 날짜·경과 일수·식물등 시간
- 실제 `disabled` 속성을 적용한 물주기 버튼: 이벤트와 저장 기능 없음
- 최근 기록 2개와 하단 홈·기록·캘린더 내비게이션
- 식물 사진·이름은 기존 상세 경로로, 기록 내비게이션은 기존 기록 경로로 연결
- 캘린더는 해당 경로·기능이 아직 없어 비활성 상태
- `모두 보기`는 식물의 경우 홈의 전체 3개 목록으로 이동하고, 기록은 `/records`로 이동
- 더보기 점은 기능 없는 장식으로 스크린리더에서 제외

기존 기술 스택과 라우트 경로를 유지했습니다. 새 의존성을 추가하지 않았으며,
Dexie·서버·Zustand store와 연결하지 않았습니다.

## 목업과 날짜

목업은 `src/data/mock/home.ts`에 있습니다. 식물 3개가 요약 수치와 일치합니다.
마지막 물주기는 2026-10-21, 2026-10-18, 2026-10-12의 고정 샘플 날짜입니다.
2026-10-24 기준 각각 3일·6일·12일 전이며, 이후 실제 날짜에 따라 증가합니다.

`src/lib/dates.ts`는 한국 시간의 달력 날짜를 사용합니다. 시간 차이를 24시간으로
나누는 대신 UTC 일련번호로 날짜를 비교해 장치 시간대·서머타임의 영향을 피합니다.
헤더와 경과 일수는 1분 간격 및 창 포커스 복귀 시 갱신됩니다.
최근 기록은 오늘부터 3일 전까지의 데모 기록 4개 중 최신 2개입니다.
주간 요약은 그 4개 중 월요일부터 오늘까지의 기록 수입니다.

## 시안과의 차이

| 항목           | 구현 차이와 이유                                                                                                                              |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 사진           | 원본 사진 파일이 없어 imagegen으로 생성한 창가·괴마옥·몬스테라·스투키 사진 사용                                                               |
| 최근 기록 사진 | 새잎 클로즈업과 물뿌리개 사진 대신 해당 식물 사진 재사용                                                                                      |
| 타이포그래피   | UI는 기존 Pretendard, 제목·식물 이름은 시스템 명조, 학명은 Georgia italic 사용. 시안의 정확한 글꼴 원본이 없어 장치별 명조 표현에 차이가 있음 |
| 식물 수        | 시안의 요약은 2, 목록은 3이므로 실제 목록에 맞춰 요약을 3으로 수정                                                                            |
| 날짜           | 시안의 고정 목요일 대신 실제 2026-10-24 토요일과 현재 날짜 사용                                                                               |
| 물주기         | 시안보다 채도를 낮추고 비활성 상태로 표시                                                                                                     |
| 좁은 화면      | 320px에서는 물주기 버튼을 날짜 아래로 이동하고 우상단 배경 문구를 숨김                                                                        |
| 기기 프레임    | 웹 콘텐츠만 구현. iPhone 외곽·상태 표시줄·홈 표시줄은 앱 UI에 포함하지 않음                                                                   |

생성 이미지와 최종 프롬프트는 [이미지 자산 기록](image-assets.md)에 있습니다.

## 검증

- TypeScript strict 검사, ESLint, Prettier, Vitest, 프로덕션 빌드
- 테스트: 기존 라우트와 탐색, 카드 수·요약 일치, disabled 버튼, 경과 일수,
  한국 시간 자정, 날짜 변경 시 갱신, 월요일 경계, 윤일·연도 경계
- 실제 브라우저에서 모바일 폭 320·375·390·430px와 데스크톱 1280px 검증
- 모바일 캡처: `screenshots/home-390.jpg`, `screenshots/home-320.jpg`

개발 서버는 `npm run dev`, 전체 검사는 `npm run check`로 실행합니다.
