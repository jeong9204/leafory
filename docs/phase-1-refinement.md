기존 크림·세이지 색상, 상단 사진과 헤더, 식물 사진 에셋, 식물 3개,

## 버튼 상태와 접근성

물주기 버튼은 실제 `disabled` 속성을 유지하므로 마우스·터치·키보드로 실행되지 않습니다.
`aria-label`의 “준비 중”과 `aria-describedby`로 연결한 “기능 준비 중”을 사용합니다.
“기능 준비 중”은 화면에도 표시하며, 비활성 상태를 색상만으로 전달하지 않습니다.
이벤트 핸들러나 데이터 저장은 추가하지 않았습니다.
활성 내비게이션은 기존 React Router의 `aria-current="page"`를 유지합니다.

## 실제 브라우저 검증과 캡처

모바일 폭 320px와 390px에서 다음을 확인했습니다.

- 문서 너비가 뷰포트 너비와 같아 가로 스크롤 없음
- 사진·식물 정보·물주기 열 사이 겹침 없음, 학명이 열 안에서 줄바꿈
- 식물 3개와 실제 disabled 물주기 버튼 3개 유지, 버튼 투명도 1
- 스크롤 최하단에서 마지막 최근 기록 카드가 내비게이션 위에 약 24px 여백을 두고 표시
- 하단 메뉴 높이 76px와 홈의 현재 페이지 상태 확인
