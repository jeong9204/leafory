## 홈 구성

2026-10-29에 첨부된 브라운톤 ‘나의 작은 정원’ 책장 이미지를 우선 기준으로 삼았습니다. 통이미지를 배경으로 쓰지 않고, 헤더·선반·식물 링크·이름표·관리 기록·장식·최근 기록을 개별 React 요소로 구성했습니다.

- 380px 이상은 3열, 320~379px는 2열입니다. CSS Grid가 등록 식물 수에 맞춰 행과 나무 선반을 늘립니다.
- 등록 식물만 한 개씩 표시하며 0개면 빈 책장과 등록 안내를 보여줍니다. 덜 찬 행은 책 소품으로 채웁니다.
- 이름은 최대 2줄이며 전체 이름을 링크의 접근 가능한 이름으로 제공합니다. 이름표의 작은 점들은 정적 장식이며 건강/수분 수치가 아닙니다.
- 화분 링크는 기존 ID의 상세 화면으로 이동합니다. 물방울 + 버튼은 기존 물주기 기록을 즉시 저장하며 중복 제출·저장 실패 처리를 유지합니다.
- 마지막 물주기 경과 일수와 오늘의 식물등 시간을 기존 CareEvent에서 조회합니다. 기록이 없으면 ‘기록 없음’이며 시간 경과로 건강 상태를 추정하지 않습니다. 진행 중 타이머는 완료 기록에 포함되지 않습니다.
- 하단 메뉴는 기존 ‘홈 | 기록 | 캘린더’입니다. 홈에서만 브라운톤을 적용하며 다른 화면의 UI를 바꾸지 않습니다.
- 기존 요약·최근 기록·등록·ZIP 백업·설치 안내 진입도 유지합니다. 최근 기록은 사진 대신 가벼운 노트 형태로 표시합니다.

## 에셋

`public/pixel/`에 직접 제작한 원본 SVG 15개(합계 25,735바이트)를 추가했습니다. 외부 이미지·원본 참고 이미지·사용자 사진을 포함하지 않습니다. CC0 고지는 해당 폴더 README에 있습니다.

- 80×96 공통 그리드의 식물 8종: 괴마옥/선인장, 몬스테라, 아데니움, 산세베리아 계열, 덩굴 관엽, 로즈마리, 다육이, 기본 화분
- 독립 장식 6종: 책, 액자, 램프, 물뿌리개, 잠자는 고양이, 아이비
- 반복 가능한 나무 텍스처 1종

화분 종류는 사용자가 입력한 학명 또는 이름의 보수적인 문자열 힌트로 선택합니다. 학명이 있으면 이름보다 우선하며 지원하지 않는 식물은 기본 화분을 씁니다. 식물 분류나 사용자 데이터를 변경하지 않습니다. 정밀한 개별 종 식별은 구현하지 않았습니다.

SVG `crispEdges`와 CSS `image-rendering: pixelated`를 사용합니다. 화분에 포인터를 올렸을 때만 짧은 기울임 애니메이션이 있으며 `prefers-reduced-motion`에서는 끕니다. 모바일의 정적 상태를 기본으로 합니다.

이번 프로토타입은 선명한 작은 SVG 도트 스타일입니다. 참고 시안의 풍부한 손작업 명암·꽃 변종·여러 도자기 무늬를 모두 동일하게 재현한 것은 아닙니다. 원한다면 이후 아트 보완 단계에서 동일한 그리드의 식물/장식 SVG를 추가·교체할 수 있습니다. 통이미지나 저해상도 사진으로 대체하지 않았습니다.

## 데이터·성능·접근성

- `loadBookshelf`는 기존 Repository의 식물·일기·관리 기록만 읽습니다. 홈에서는 대표 사진·일기 사진 Blob을 가져오거나 Blob URL을 만들지 않습니다.
- DB 스키마·모델·기존 사진·일기·관리 이벤트·타이머·백업 형식을 변경하지 않았습니다. 실제 앱에 샘플을 넣지 않습니다.
- 주요 링크와 물주기 버튼은 최소 44px, 키보드 포커스 표시 유지. 화분 링크와 기록 버튼은 중첩하지 않습니다.
- 장식은 빈 alt와 `aria-hidden`으로 제외합니다. 식물 화분 이미지만 의미 있는 대체 텍스트를 갖습니다.
- 기존 safe-area와 하단 네비게이션 콘텐츠 여백을 유지합니다. 새 SVG는 기존 PWA 빌드 플러그인이 자동 precache하므로 별도 서비스 워커 정책 변경은 없습니다.
