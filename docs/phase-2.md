# Phase 2 — 식물 상세 화면 UI

이전에 첨부된 두 번째 이미지(괴마옥 상세)를 기준으로 구현했습니다.
확정된 홈 디자인과 이미지 에셋, 공통 하단 내비게이션은 그대로 유지합니다.

## 구현 범위

- `/plants/euphorbia`, `/plants/monstera`, `/plants/snake-plant`에 해당 식물의 상세 정보 표시
- 홈 목록으로 돌아가기 링크, 식물 이름·학명, 대표 사진·상태·메시지
- 마지막 물주기, 오늘의 식물등 사용 시간, 실제 목업 기록 수
- 빠른 기록·일기 쓰기·메모 수정 버튼은 native `disabled` 상태. 작성 버튼의 준비 중 안내도 표시
- 타임라인/사진 탭은 마우스·터치 및 방향키·Home/End로 전환
- 사진과 성장 관찰·물주기·식물등 이벤트를 함께 표시하는 타임라인
- 날짜 역순 정렬, 사진이 없는 관리 이벤트와 빈 상태 지원
- 읽기 전용 식물 메모
- 알 수 없는 식물 ID에 안내 화면과 홈 복귀 링크 제공

Dexie, 서버, 실제 기록 작성·삭제·메모 저장은 연결하지 않았습니다.
패키지와 프로젝트 설정에 새 의존성을 추가하지 않았습니다.

## 디자인 이미지와 비교

| 요소             | 구현 및 차이                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------------ |
| 분위기           | 홈과 같은 크림·세이지·포레스트, 명조 제목·Pretendard UI, 둥근 카드 사용                                |
| 상단 사진과 상태 | 시안처럼 좌측 사진·우측 상태와 메시지. 사진은 홈의 기존 괴마옥 에셋 사용                               |
| 관리 통계        | 390px에서는 우측 하단에 3열, 320px에서는 사진 아래 전체 폭 3열로 배치해 가독성 확보                    |
| 총 기록 수       | 시안의 12개 대신 실제 상세 목업 수와 일치하는 3개                                                      |
| 기록 날짜        | 성장 관찰은 한국 시간의 오늘, 물주기는 홈과 같은 고정 샘플 날짜, 식물등 기록은 그 전날. 날짜 역순 표시 |
| 타임라인 사진    | 시안의 새잎·물뿌리개·식물등 개별 사진 대신 기존 대표 사진을 재사용하는 임시 목업                       |
| 식물 장식        | 별도 일러스트 대신 옅은 Lucide Sprout 장식 사용                                                        |
| 버튼             | 시안의 색상은 유지하면서 기록 작성·메모 수정은 비활성화. 실제 기능이 없다는 안내 추가                  |
| 하단 메뉴        | 확정된 공통 내비게이션 재사용. 시안의 강제 홈 활성 표시 대신 현재 경로 기준 상태 유지                  |
| 작은 화면        | 학명·설명 줄바꿈 허용, 통계 위치 조정. 콘텐츠는 세로 스크롤로 열람                                     |
| 기기 프레임      | 웹 콘텐츠만 구현. iPhone 외곽·상태 표시줄·홈 표시줄은 앱에 포함하지 않음                               |

## 홈 회귀 검증

- 홈 페이지, PlantCard, 공통 하단 내비게이션, 홈 목업, `src/index.css`의 파일 해시가 작업 전후 동일
- [320px 홈 캡처](screenshots/home-phase2-regression-320.jpg), [390px 홈 캡처](screenshots/home-phase2-regression-390.jpg)를 기존 화면과 시각 비교
- 기존 홈 UI·날짜 계산·라우팅 테스트 유지, 상세 왕복 후 홈의 식물 3개와 활성 메뉴 상태 검증
- 상세 CSS는 전용 파일과 `.detail-*` 선택자에 한정해 홈 스타일에 영향을 주지 않음

## 자동 검사

`npm run check`로 TypeScript strict·ESLint·Prettier·Vitest 33개·프로덕션 빌드를 모두 통과했습니다.
새 테스트는 세 식물의 ID별 정보, 목업 수와 통계 일치, 준비 중 버튼 접근성 설명,
탭 전환과 키보드 포커스, 홈 왕복, 없는 ID, 빈 기록/사진 및 사진 없는 이벤트를 확인합니다.

개발 서버: `npm run dev`, 예시 경로: `/plants/euphorbia`.
