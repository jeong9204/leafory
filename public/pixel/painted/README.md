# Leafory painted pixel sprites

20 independent transparent sprites generated for Leafory on 2026-10-30 using
OpenAI's built-in image generation tool. No third-party sprite packs, user
photos, diary Blobs, or crops from the reference mockup are included.
The previous 15 original SVGs remain unchanged in the parent directory.

These files are newly generated illustrations. No third-party attribution or
font is embedded. The parent directory's CC0 declaration describes the authored
SVGs; it does not assert exclusive copyright over AI-generated images.

- Plants: adenium, cactus, default, evergreen (Euonymus), monstera,
  philodendron, rosemary, snake, succulent, trailing.
- Props: books, frame, lamp, cat, globe, lantern, house, spray, can.
- Border: ivy.

The original generated PNGs remain outside the app workspace. Delivery copies
are WebP (quality 82, alpha quality 100), preserving source dimensions, aspect
ratio and transparency. Most are 1254 × 1254; ivy is 1024 × 1536.
Total delivery size: 3,900,178 bytes. No runtime image library is required.
`pixel-assets.ts` provides the replaceable asset mapping; the UI uses contain,
bottom alignment and image-rendering: pixelated. No photo data is transformed.

See `docs/phase-11-final-design.md` for the prompt set, visual limitations,
comparison captures and verification. These are decorative hints, not botanical
identification or plant-health assessments.
