# Leafory pixel garden assets

Original SVG pixel artwork created for Leafory Phase 11 (2026-10-29).
No third-party artwork, reference bitmap, photos, fonts, or embedded raster data.
Artwork dedicated to the public domain under CC0 1.0 Universal.

Plant sprites share an 80 × 96 grid, dark olive outlines, stepped leaf edges,
and cream/blue/terracotta/olive ceramic palettes. Books, lamp, frame, watering
can, sleeping cat, ivy, and a 64 × 64 wood tile are independent reusable assets.
SVG uses crispEdges; UI also applies image-rendering: pixelated.
These are decorative illustrations, not botanical identification or health indicators.
